1. MİMARİ VE GENEL BAKIŞ
------------------------------------------------------------------------------
Enterprise seviyesindeki web ve mobil uygulamalarda kullanıcı deneyimini en üst
düzeye çıkarmak için çoklu dil desteği (i18n) ve yerelleştirme (l10n) kritik bir
ihtiyaçtır. Adım 17 kapsamında sistem, hem HTTP Header (Accept-Language) hem de
URL sorgu parametresi (?lang=tr|en|de) üzerinden dinamik olarak dil çözümleyebilen
stateless ve esnek bir altyapıya kavuşturulmuştur.

Desteklenen Diller:
- Türkçe  (tr-TR / tr) -> Varsayılan (Default) Sistem Dili
- İngilizce (en-US / en) -> Global ve API İletişim Dili
- Almanca  (de-DE / de) -> Avrupa Bölgesel Dili

2. TEMEL BİLEŞENLER VE MİMARİ
------------------------------------------------------------------------------
A) SmartLocaleResolver (com.berkeozder.i18n.SmartLocaleResolver)
   - Spring Web MVC'nin 'AcceptHeaderLocaleResolver' sınıfını genişletir.
   - Çözümleme Önceliği:
     1. ?lang=tr | ?lang=en | ?lang=de (URL sorgu parametresi en yüksek önceliktedir)
     2. Accept-Language header (örn: "de-DE,de;q=0.9,en;q=0.8")
     3. Fallback: Sistem varsayılanı (tr_TR)
   - Stateless REST API uyumluluğu için 'setLocale' metodu UnsupportedOperationException
     fırlatmayacak şekilde güvenli hale getirilmiştir.

B) I18nConfig (com.berkeozder.config.I18nConfig)
   - MessageSource: 'ReloadableResourceBundleMessageSource' kullanılarak
     'classpath:messages' ve 'classpath:ValidationMessages' dosyaları UTF-8 olarak yüklenir.
   - fallbackToSystemLocale: false ayarlanarak sunucu işletim sistemi dilinden bağımsız
     olarak yapılandırılmış varsayılan dile düşmesi garanti edilir.
   - LocalValidatorFactoryBean: Hibernate Validator / Bean Validation mesajlarını
     MessageSource ile entegre eder (Örn: @NotBlank(message = "{blog.title.not.blank}")).

C) MessageService (com.berkeozder.i18n.MessageService)
   - Servis ve controller katmanlarında dil çözümlemeyi kolaylaştıran merkezi yardımcı servis.
   - getMessage(String code): LocaleContextHolder üzerinden thread-local aktif dile göre çözer.
   - getMessage(String code, Object... args): {0}, {1} parametrelerini dinamik yerleştirir.
   - getMessage(String code, Locale locale, Object... args): Belirli bir hedef dilde mesaj üretir.
   - getMessageOrDefault(String code, String defaultMessage): Anahtar bulunamadığında varsayılana döner.

D) RESTful API (com.berkeozder.controller.api.impl.I18nApiImpl)
   - GET /api/v1/i18n/current: O anki istek bağlamındaki aktif dil, ülke, displayName ve örnek çeviriler.
   - GET /api/v1/i18n/languages: Desteklenen dillerin listesi (kod, ad, bayrak emojisi).
   - GET /api/v1/i18n/messages: React / Vue / Angular ön yüzleri için tam çeviri sözlüğü.
