# Abdullah Berke Ozder - Portfolio

Welcome to my project portfolio. This repository brings together selected frontend and full-stack applications that demonstrate my work with modern React architecture, responsive interfaces, Supabase-backed data flows, and practical product thinking.

## About

I build user-focused web applications with clean component structure, maintainable styling, and thoughtful data handling. My current focus is on React, Vite, Supabase, client-side routing, server state management, and production-ready project organization.

## Getting Started

Open a project folder and follow its README:

```bash
cd the-welding-expert-app
npm install
npm run dev
```

Environment files are not committed. Use each project's `.env.example` file as a template for local setup.
