# Contributing to Portfolio

Thank you for your interest in contributing to this portfolio! Here are some guidelines to follow:

## 🐛 Reporting Issues

Found a bug? Have a suggestion? Please create an issue on GitHub with:

- Clear description of the problem
- Steps to reproduce (if applicable)
- Expected behavior
- Actual behavior
- Screenshots (if relevant)

## 💡 Making Changes

1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add amazing feature'`)
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a Pull Request

## 📝 Code Guidelines

- Write clean, readable code
- Use meaningful variable names
- Add comments for complex logic
- Follow the existing code style
- Test your changes before submitting

## ✅ Before Submitting a PR

- Ensure your code follows the project style
- Test your changes thoroughly
- Update documentation if necessary
- Keep commits clean and descriptive

## 📧 Questions?

Feel free to open an issue or contact me directly.

Happy coding! 🚀
